# Plantilla de mensajes para chat de Incidentes y Novedades

## Para prioridad alta:
Se debe realizar la acción de comunicación de acuerdo al comentario Notificación Mesas de crisis

## Para prioridad media:
```
Hola, [nombre propio del requester]. Gracias por reportar este ticket y brindarnos visibilidad. El caso ya se encuentra clasificado. Ten presente que la atención se gestiona con base en los acuerdos de nivel de servicio (SLA), por lo que recibirás notificaciones cuando se requiera información, tengamos avances o se solucione el incidente.

Último reporte:
Próximo reporte esperado:
```
 
### Para prioridad baja:
```
Hola, [nombre propio del requester]. Queremos notificar que el ticket ya se encuentra clasificado y en la cola de atención de incidentes de prioridad inicial. Estaremos informándote sobre avances o posibles soluciones conforme el caso evolucione, dentro de los tiempos definidos en nuestro SLA. 
```
